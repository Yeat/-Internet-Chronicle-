# 公众号文稿使用说明

## 文件

| 文件 | 用途 |
| --- | --- |
| `我不得不把才华埋葬在昨天-公众号文稿.md` | 完整成稿（含配图位置与图注） |
| `preview.html` | 浏览器预览排版效果 |
| `images/` | 5 张配图，可直接上传公众号素材库 |

## 建议标题（可择一）

1. **他把 DeepSeek 的核心算子写完，接着说了一句很丧的话**（推荐）
2. 手中多了齿轮，心中少了节拍
3. DeepSeek 工程师写完 V4.1 算子后：我不得不把才华埋葬在昨天

## 建议摘要

DeepSeek 工程师刘胜与写完 V4.1 主 Attention 后发文：活大概还在，但手写算子那套最让他上瘾的干法正在过时。AI 会读 CUDA/PTX/SASS 了，他更可能转成指挥 Agent 的“机甲驾驶员”。

## 配图上传顺序

1. `cover-bury-talent.jpg` — 封面 / 文首  
2. `gpu-kernel-layers.jpg` — 技术栈小节  
3. `mecha-pilot-desk.jpg` — 机甲驾驶员小节  
4. `window-knitting-machine.jpg` — 织毛衣比喻  
5. `two-futures-fork.jpg` — 两条未来小节  

封面比例均为 16:9，适合公众号头条大图与正文插图。

## 排版提示

- 正文短段为主，方便手机阅读  
- 小标题保留「01｜」形式，利于扫读  
- 引用原文处可用公众号“引用”样式  
- 表格在部分编辑器中支持不佳：若粘贴丢失，可改成条目列表
