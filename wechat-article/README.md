# 公众号文稿使用说明

## 文件

| 文件 | 用途 |
| --- | --- |
| `我不得不把才华埋葬在昨天-公众号文稿.md` | 完整成稿（含配图位置与图注） |
| `preview.html` | 浏览器预览排版效果 |
| `images/` | 5 张配图，可直接上传公众号素材库 |

2. 不会失业，但必须转业：一位 DeepSeek 算子工程师的深夜独白
3. 手中多了齿轮，心中少了节拍

## 排版提示

- 正文短段为主，方便手机阅读  
- 小标题保留「01｜」形式，利于扫读  
- 引用原文处可用公众号“引用”样式  
- 表格在部分编辑器中支持不佳：若粘贴丢失，可改成条目列表
