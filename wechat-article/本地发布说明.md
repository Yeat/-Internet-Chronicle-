# 本地发布到微信公众号

这篇已经按「你自己在电脑上发」准备好了。云端登不了你的公众号，所以发布动作在你本机完成。

## 你要打开的文件

```
wechat-article/
├── 本地发布说明.md          ← 就是本文件
├── paste-to-wechat.html     ← 粘贴正文用（内联样式，适合公众号）
├── preview.html             ← 浏览器预览排版
├── 我不得不把才华埋葬在昨天-公众号文稿.md
└── images/
    ├── 01-cover.jpg         ← 封面 / 文首图
    ├── 02-gpu-layers.jpg
    ├── 03-mecha-pilot.jpg
    ├── 04-knitting.jpg
    └── 05-two-futures.jpg
```

## 推荐标题

他把 DeepSeek 的核心算子写完，接着说了一句很丧的话

## 推荐摘要

DeepSeek 工程师写完 V4.1 主 Attention 后发文：活大概还在，但手写算子那套最让他上瘾的干法正在过时。

## 操作步骤（约 5 分钟）

1. 打开 [公众号后台](https://mp.weixin.qq.com) → **草稿箱** → **新的创作** → **文章**
2. 填标题、作者、摘要
3. **封面**：上传 `images/01-cover.jpg`（16:9）
4. 用浏览器打开本目录下的 `paste-to-wechat.html`
5. 全选页面内容（`Ctrl/Cmd + A`）→ 复制（`Ctrl/Cmd + C`）
6. 粘贴进公众号编辑器（`Ctrl/Cmd + V`）
7. 若图片变成裂图或本地路径：在编辑器里把图删掉，再按顺序从 `images/` 重新插入  
   `01` → `02` → `03` → `04` → `05`
8. 预览手机效果 → 存草稿 / 发表

## 注意

- 公众号编辑器经常吃掉外链图，**本地图一般要重新上传一遍**，这是正常现象
- 粘贴后若引用块样式丢了，用编辑器自带「引用」重设一下即可
- 不想用 HTML 时，也可以打开 Markdown 文稿，纯文本粘贴后再手动插图

## 一键打包（可选）

在仓库根目录执行：

```bash
cd wechat-article && zip -r ../wechat-local-publish.zip paste-to-wechat.html preview.html *.md images/
```

把 `wechat-local-publish.zip` 拷到自己电脑解压，按上面步骤发。
